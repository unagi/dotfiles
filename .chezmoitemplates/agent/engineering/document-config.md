# 文書・設定の変更

- `common/change-control.md` の承認条件を守り、対象の正本・参照元・配布範囲を確認する。既読不変なら再読不要。
- 文書は目的・読者・既存形式に合わせ、参照切れ・重複・原資料との不一致を確認する。指示文書の整備・レビューでは `common/project-instructions-guideline.md` も読む。
- 設定は構文、値、既定値、環境差、利用側への影響を確認する。API・CLI等の仕様を確認する場合は `common/technical-reference.md`、検証コマンド実行では `common/development.md` を読む。
- コードやテストを変更する必要が生じたら該当ガイドを追加し、対象範囲・承認を確認する。文書だけの変更へコード調査・TDDを一律に要求しない。
- 確認した対象版・差分・未検証部分を共通回答形式で返す。
